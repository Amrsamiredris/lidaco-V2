# Changelog & Edit History

This file tracks all the edits made to the project, attached to version numbers, explaining what was done, what worked, and what didn't.

## [v1.1.0] - Multi-Language Expansion & Arabic RTL Support
- **What we did:** Added 6 new international languages (Arabic `ar`, Russian `ru`, Spanish `es`, French `fr`, German `de`, Turkish `tr`) alongside English (`en`) and Chinese (`zh`), bringing the total to 8 languages. Implemented native RTL bidirectional layout support for Arabic, upgraded the desktop and mobile language selectors to support 8 locales with native names and flags, and ensured 100% key parity across all 125 static pages.
- **What worked:** Static builds compiled with 100% success (125/125 static pages generated), full RTL support on Arabic routes, and seamless switching across all 8 languages.
